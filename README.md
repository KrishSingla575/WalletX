# WalletX 💰

A modern, feature-rich fintech dashboard application for managing personal finances, cards, transactions, and currency exchange.


## ✨ Features

### 📊 Dashboard
- Real-time financial overview with animated statistics
- Interactive card management with flip animations
- Cash flow visualization with area charts
- Spending breakdown by category (pie chart)
- Quick action buttons for common operations

### 💳 Card Management
- View all your cards with beautiful gradients
- Add new cards with real-time preview
- Card actions: Freeze/Unfreeze, Set Limit, View PIN, Cancel
- Visual feedback with toast notifications
- Card flipping animation for additional options

### 📝 Transactions
- Complete transaction history
- Categorized spending (Shopping, Food, Transport, Bills, etc.)
- Visual transaction cards with color-coded types
- Income/expense tracking

### 📈 Analytics
- Multiple time periods (1 month, 3 months, 7 months, 1 year)
- Income vs Expenses area charts
- Top spending categories with progress bars
- Savings goal tracker with donut chart
- Key metrics: Total Income, Total Spent, Net Savings, Average per Month

### 🔔 Additional Features
- Send/Receive money modals with contact selection
- QR code generation for receiving payments
- Toast notifications for user actions
- Fully responsive design
- Smooth animations and hover effects

## 🚀 Tech Stack

- **React** - UI Framework
- **Recharts** - Charting library for data visualization
- **CSS-in-JS** - Inline styles with dynamic theming
